# Página de vendas e informações sobre Tacos

**Descrição:**

Este projeto é uma página web simples, criada com HTML e CSS, destinada à venda de tacos. O design é simples, contém um formulário de contato para que os clientes possam entrar em contato para fazer pedidos ou tirar dúvidas.

**Funcionalidades:**

* **Vitrine de produtos:** Apresenta os diferentes tipos de tacos disponíveis, com tabelas de preços.
* **Formulário de contato:** Permite que os clientes entrem em contato para fazer pedidos ou tirar dúvidas.
* **Design responsivo:** A página se adapta a diferentes tamanhos de tela, garantindo uma boa experiência para o usuário em dispositivos móveis e desktops.

**Tecnologias utilizadas:**

* **HTML5:** Estrutura da página.
* **CSS3:** Estilização da página.
